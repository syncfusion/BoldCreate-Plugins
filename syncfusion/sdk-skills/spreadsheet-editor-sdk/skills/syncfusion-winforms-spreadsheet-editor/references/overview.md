# Windows Forms Spreadsheet Overview

The [WinForms Spreadsheet](https://www.syncfusion.com/winforms-ui-controls/spreadsheet) is an Excel-inspired control that allows you to create, edit, view, and format Microsoft Excel files without Excel being installed. It provides an absolute ease-of-use UI experience with an integrated ribbon to cover any possible business scenario. Spreadsheet comes with a built-in calculation engine with support for 400+ most widely used formulas.

## Key Features

| Feature | Description |
|---|---|
| **Ribbon** | Ribbon integrated with organically enhanced UI experience. |
| **Editing and Selection** | Interactive support for editing and cell selection in a workbook. |
| **Formulas** | Support for 400+ most widely used formulas; add, remove, and edit formulas like in Excel. |
| **Name Manager** | Supports named ranges in formulas. Define name for a cell range and use it in formulas easily. |
| **Data Validation** | Ensures data integrity by enforcing end users to enter valid data; displays error messages for invalid data. |
| **Floating Cells** | When text exceeds the length of a cell, it floats to the adjacent cell. |
| **Merge Cells** | Merge two or more adjacent cells into a single cell and display contents of one cell. |
| **Conditional Formatting** | Excel-compatible conditional formatting with Data Bars, Icon Sets, and Color Scales. |
| **Cell Comments** | Comments that provide additional information about a cell value. |
| **Hyperlinks and Bookmarks** | Import, create, and edit hyperlinks and bookmarks for navigation within workbooks. |
| **Undo/Redo** | Undo or redo changes made in the workbook. |
| **Clipboard Operations** | Cut/Copy/Paste operations in Spreadsheet. |
| **Fill Series** | Automatically fill cells with data that follows or completes a pattern. |
| **Freeze Panes** | Freeze rows/columns to keep them visible while scrolling. |
| **Resizing and Hiding** | Interactively resize or hide/unhide rows and columns. |
| **Charts, Pictures, and Textboxes** | Import Charts, Pictures, and Textboxes from Excel. |
| **Sparklines** | Import Sparklines from Excel files. |
| **Outlines** | Group or ungroup rows and columns. |
| **Workbook and Worksheet Protection** | Protect worksheets and lock down the structure and window of a workbook. |
| **Conversion** | Export workbook to PDF, HTML, Image, and CSV formats. |
| **Zooming** | Zoom in and zoom out of the worksheet view. |
| **Localization** | Localize all static text in Ribbon and dialogs to any desired language. |
| **Supported File Types** | Import XLS, XLSX, XLSM, XLT, XLTX, and CSV files. |
