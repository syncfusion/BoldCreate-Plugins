# Name Manager

> Manage named ranges for use in formulas in WPF Spreadsheet control.

---

## Overview

Allows defining names for cell ranges, making formulas easier to read and maintain. Named ranges can be managed through the Name Manager dialog.

---

## Key Features
- Define, edit, and delete named ranges
- Use names in formulas (e.g., `=SUM(SalesData)`)
- Name Manager dialog for management

---

## Example

Assign a name to a range (e.g., `A1:A10` as `SalesData`) and use it in formulas.
