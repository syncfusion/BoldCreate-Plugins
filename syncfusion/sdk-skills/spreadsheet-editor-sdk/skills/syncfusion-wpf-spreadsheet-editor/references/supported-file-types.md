# Supported File Types

> Import and export various Excel file formats in WPF Spreadsheet control.

---

## Overview

Supports opening, editing, and saving multiple Excel file types, ensuring compatibility with different versions and formats.

---

## Key Features
- Import/export XLS, XLSX, XLSM, XLT, XLTX, CSV
- Compatibility with Microsoft Excel
- Seamless file operations

---

## Example

Open a `.xlsx` file, edit, and save as `.csv` or other supported formats.
