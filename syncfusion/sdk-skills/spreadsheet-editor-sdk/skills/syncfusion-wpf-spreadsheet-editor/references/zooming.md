# Zooming

> Zoom in and out of the worksheet view in WPF Spreadsheet control.

---

## Overview

Allows users to adjust the zoom level for better visibility and navigation of worksheet content.

---

## Key Features
- Zoom in/out with slider or commands
- Fit to window
- Keyboard and mouse support

---

## Example

Use the zoom slider or Ctrl+Mouse Wheel to change the zoom level.
