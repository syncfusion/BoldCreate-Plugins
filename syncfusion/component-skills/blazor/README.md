# Syncfusion Blazor Components

Skills for building Blazor apps with Syncfusion Blazor components: data grid, charts, scheduler, editors, navigation and more, with setup, APIs, theming and examples.

Each skill is a folder with a `SKILL.md` file and usually a `references/` folder. Your agent loads a skill when your request matches its description.

## Installation

- **BoldCreate Connect:** open **Marketplace**, find **Syncfusion Blazor Components**, and click **Install**.
- **Cursor:** add this repository as a team marketplace, then install **Syncfusion Blazor Components**.
- **Claude Code:** `/plugin marketplace add syncfusion/BoldCreate-Plugins`, then `/plugin install syncfusion-blazor@boldcreate-plugins`.

The skills need no license key to install. Building an app with Syncfusion packages still needs a Syncfusion license key ([free community license](https://www.syncfusion.com/products/communitylicense)).
