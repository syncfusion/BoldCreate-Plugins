# Syncfusion JavaScript UI Controls

Skills for building JavaScript and TypeScript apps with Syncfusion Essential JS 2 controls: data grid, charts, scheduler, editors, navigation and more, with setup, APIs, theming and examples.

Each skill is a folder with a `SKILL.md` file and usually a `references/` folder. Your agent loads a skill when your request matches its description.

## Installation

- **BoldCreate Connect:** open **Marketplace**, find **Syncfusion JavaScript UI Controls**, and click **Install**.
- **Cursor:** add this repository as a team marketplace, then install **Syncfusion JavaScript UI Controls**.
- **Claude Code:** `/plugin marketplace add syncfusion/BoldCreate-Plugins`, then `/plugin install syncfusion-javascript@boldcreate-plugins`.

The skills need no license key to install. Building an app with Syncfusion packages still needs a Syncfusion license key ([free community license](https://www.syncfusion.com/products/communitylicense)).
