### Basic Pie Chart

```csharp
@Html.EJS().AccumulationChart("pieChart")
    .Series(series =>
    {
        series.Type(Syncfusion.EJ2.Charts.AccumulationChartType.Pie)
              .DataSource(data)
              .XName("Category")
              .YName("Value")
              .Add();
    })
    .Render()
```

```csharp
@Html.EJS().AccumulationChart("doughnutChart")
    .Series(series =>
    {
        series.Type(Syncfusion.EJ2.Charts.AccumulationChartType.Doughnut)
              .DataSource(data)
              .XName("Category")
              .YName("Value")
              .InnerRadius("40%")
              .Add();

    .Render()
```
