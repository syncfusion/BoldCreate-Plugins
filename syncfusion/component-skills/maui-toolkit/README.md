# Syncfusion Toolkit for .NET MAUI

Skills for building .NET MAUI apps with the free, open-source Syncfusion Toolkit for .NET MAUI: charts, buttons, cards, calendar, navigation and more, with setup, APIs, theming and examples.

Each skill is a folder with a `SKILL.md` file and usually a `references/` folder. Your agent loads a skill when your request matches its description.

## Installation

- **BoldCreate Connect:** open **Marketplace**, find **Syncfusion Toolkit for .NET MAUI**, and click **Install**.
- **Cursor:** add this repository as a team marketplace, then install **Syncfusion Toolkit for .NET MAUI**.
- **Claude Code:** `/plugin marketplace add syncfusion/BoldCreate-Plugins`, then `/plugin install syncfusion-maui-toolkit@boldcreate-plugins`.

The Syncfusion Toolkit for .NET MAUI is free and open source (MIT), so no Syncfusion license key is needed.
