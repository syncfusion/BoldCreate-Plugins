# Syncfusion .NET MAUI Controls

Skills for building .NET MAUI apps with Syncfusion .NET MAUI controls: data grid, charts, scheduler, inputs, navigation and more, with setup, APIs, theming and examples.

Each skill is a folder with a `SKILL.md` file and a `references/` folder. Your agent loads a skill when your request matches its description, for example "add a data grid with paging".

## Installation

- **BoldCreate Connect:** open **Marketplace**, find **Syncfusion .NET MAUI Controls**, and click **Install**.
- **Cursor:** add this repository as a team marketplace, then install **Syncfusion .NET MAUI Controls**.
- **Claude Code:** `/plugin marketplace add syncfusion/BoldCreate-Plugins`, then `/plugin install syncfusion-maui@boldcreate-plugins`.

The skills need no license key to install. Building an app with Syncfusion packages still needs a Syncfusion license key ([free community license](https://www.syncfusion.com/products/communitylicense)).
