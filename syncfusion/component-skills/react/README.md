# Syncfusion React UI Components

Skills for building React apps with Syncfusion React UI components: data grid, charts, scheduler, editors, navigation and more, with setup, APIs, theming and examples.

Each skill is a folder with a `SKILL.md` file and a `references/` folder. Your agent loads a skill when your request matches its description, for example "add a data grid with paging".

## Installation

- **BoldCreate Connect:** open **Marketplace**, find **Syncfusion React UI Components**, and click **Install**.
- **Cursor:** add this repository as a team marketplace, then install **Syncfusion React UI Components**.
- **Claude Code:** `/plugin marketplace add syncfusion/BoldCreate-Plugins`, then `/plugin install syncfusion-react@boldcreate-plugins`.

The skills need no license key to install. Building an app with Syncfusion packages still needs a Syncfusion license key ([free community license](https://www.syncfusion.com/products/communitylicense)).
