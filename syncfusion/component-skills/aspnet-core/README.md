# Syncfusion ASP.NET Core UI Controls

Skills for building ASP.NET Core apps with Syncfusion ASP.NET Core UI controls and Tag Helpers: data grid, charts, scheduler, editors and more, with setup, APIs, theming and examples.

Each skill is a folder with a `SKILL.md` file and usually a `references/` folder. Your agent loads a skill when your request matches its description.

## Installation

- **BoldCreate Connect:** open **Marketplace**, find **Syncfusion ASP.NET Core UI Controls**, and click **Install**.
- **Cursor:** add this repository as a team marketplace, then install **Syncfusion ASP.NET Core UI Controls**.
- **Claude Code:** `/plugin marketplace add syncfusion/BoldCreate-Plugins`, then `/plugin install syncfusion-aspnet-core@boldcreate-plugins`.

The skills need no license key to install. Building an app with Syncfusion packages still needs a Syncfusion license key ([free community license](https://www.syncfusion.com/products/communitylicense)).
