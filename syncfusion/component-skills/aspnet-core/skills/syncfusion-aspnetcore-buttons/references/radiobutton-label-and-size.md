# Label and Size – ASP.NET Core RadioButton

## Label Positioning

### Label Before (Default)

```cshtml
<ejs-radiobutton id="r1" label="Option" labelPosition="Before"></ejs-radiobutton>
```

### Label After

```cshtml
<ejs-radiobutton id="r2" label="Option" labelPosition="After"></ejs-radiobutton>
```

## Size Variants

### Normal Size

```cshtml
<ejs-radiobutton id="normal" label="Normal"></ejs-radiobutton>
```

### Small Size

```cshtml
<ejs-radiobutton id="small" cssClass="e-small" label="Small"></ejs-radiobutton>
```

## Custom Label

```cshtml
<label>
    <ejs-radiobutton id="custom" name="group1"></ejs-radiobutton>
    Custom label with <strong>formatting</strong>
</label>
```
