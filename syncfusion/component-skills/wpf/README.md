# Syncfusion WPF Controls

Skills for building WPF desktop apps with Syncfusion WPF controls: data grid, charts, scheduler, docking, ribbon and more, with setup, APIs, theming and examples.

Each skill is a folder with a `SKILL.md` file and a `references/` folder. Your agent loads a skill when your request matches its description, for example "add a data grid with paging".

## Installation

- **BoldCreate Connect:** open **Marketplace**, find **Syncfusion WPF Controls**, and click **Install**.
- **Cursor:** add this repository as a team marketplace, then install **Syncfusion WPF Controls**.
- **Claude Code:** `/plugin marketplace add syncfusion/BoldCreate-Plugins`, then `/plugin install syncfusion-wpf@boldcreate-plugins`.

The skills need no license key to install. Building an app with Syncfusion packages still needs a Syncfusion license key ([free community license](https://www.syncfusion.com/products/communitylicense)).
